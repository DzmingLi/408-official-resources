#+title: 408 官方考试资料

本仓库用于收录全国硕士研究生招生考试计算机学科专业基础（俗称408）的官方相关资料，包括：

- 官方发布的考试大纲
- 历年真题与评分标准
- 官方发布的题型示例

真题和题型示例以教育部教育考试院（原教育部考试中心）出版的官方考试大纲为准。

目前没有明确资料给出考场试卷的排版参数，模板仍在完善中，目标是尽可能真实还原官方排版。欢迎熟悉相关字体、排版或印刷流程的读者提供建议。

真题文字订正及考纲范围变更标记统一记录于 [[file:真题订正.org][真题订正与注解]]。新版题型示例复用了历年真题，本仓库仅保留旧版题型示例。

* 目录

- =考试大纲/= ：跟随最新考试大纲更新，按四门专业课整理为 Org 文件。
- =真题订正.org= ：真题文字订正、考纲范围变更标记及学习注解的统一记录。
- =历年真题+参考解答/= ：各年份试题和已有参考答案的 Typst 源文件。
- =旧版题型示例/= ：官方旧版题型示例及自制详细解析（非官方）。
- [[file:分类汇编/README.org][分类汇编/]]：按考试大纲分讲的分类汇编；仅按需求逐讲增加，收录年份截止2022年，保留2023～2026年整卷练习。
- =内容来源/= ：官方扫描资料，使用 Git LFS 保存。

如发现录入错字、图片或排版错误，欢迎提交 Issue 或 PR，并指出对应的官方资料位置。

* PDF 与构建

PDF 通过 [[https://github.com/DzmingLi/408-official-resources/releases][GitHub Releases]] 提供，随仓库更新自动构建。运行 =nix build= 后，输出位于 =result/= ，只包含 PDF。

历年试卷统一发布在 [[https://github.com/DzmingLi/408-official-resources/releases/tag/pdf-latest][PDF downloads]]；分类汇编按科目独立发布，默认分支更新后自动构建并更新：

- [[https://github.com/DzmingLi/408-official-resources/releases/tag/collection-数据结构][数据结构分类汇编]]
- [[https://github.com/DzmingLi/408-official-resources/releases/tag/collection-计算机组成原理][计算机组成原理分类汇编]]
- [[https://github.com/DzmingLi/408-official-resources/releases/tag/collection-操作系统][操作系统分类汇编]]
- [[https://github.com/DzmingLi/408-official-resources/releases/tag/collection-计算机网络][计算机网络分类汇编]]

PDF文件命名如下：

- =年份.pdf= ：阅读版。
- =年份-print.pdf= ：小册子打印版，使用 ISO B4 横向纸张，100% 实际大小、双面短边翻转；不要再次启用小册子拼版。
- =年份-answers.pdf= 与 =年份-answers-print.pdf= ：参考答案阅读版、打印版。
- =old-sample.pdf= 与 =old-sample-print.pdf= ：题型示例阅读版、打印版。
- =old-sample-answers.pdf= 与 =old-sample-answers-print.pdf= ：题型示例解析阅读版、打印版。

分类汇编的收录范围、分类规则、答案提取与合并方式见 [[file:分类汇编/README.org][分类汇编说明]]。

* 答案来源

2009—2014年真题答案可分别在2010、2012、2013、2015、2016年考试大纲的附录中核对，不要求一定具备真题次年的那一版考纲。2009—2012、2014年的答案现按考纲录入，不收录汇编另加的评分说明和扩写；2013年按指定继续保留高等教育出版社2015年《考研计算机专业基础综合历年真题标准解析》的解析。

** 早年综合题答案来源核对

2026年10月25日人工阅读考纲扫描页，对照现有2009—2014年每年41～47题的答案文字、算法、结果及图表内容；这不是对现有Typst逐字无误的认证。

| 真题年份 | 考纲版本 | 书内答案页 | PDF页（从1计） |
|----------+----------+------------+----------------|
| 2009 | 2010年 | 32～37 | 38～43 |
| 2010 | 2012年 | 34～38 | 39～43 |
| 2011 | 2012年 | 51～57 | 56～62 |
| 2012 | 2013年 | 54～59 | 58～63 |
| 2013 | 2015年 | 50～55 | 54～59 |
| 2014 | 2015年；末尾用2016年补核 | 68～73；55～56 | 72～77；59～60 |

以下记录的是切换考纲版本前的旧稿差异。主要算法、结果、表格及多数解释可在考纲中找到，并非全部由汇编另行撰写；但“答案要点相同”不等于汇编全文都是官方原文。旧稿差异包括：

- 2009年第41题，考纲仅写“举例说明（略）”，现稿增加两个反例图及说明；第43题考纲只列2.5%、0.1%并略去计算，现稿补写计算过程；第46题现稿增加地址划分图及解释，部分过程表述与考纲不同。
- 2010年第41题，考纲给散列表与12/7、18/7两个结果，现稿另列散列及平均查找长度的逐步计算；其余综合题的主要答案可在考纲中对应找到。
- 2011—2014年现稿中的大量“评分说明”、分问分值，以及2011年第42题的备用归并程序、2013年第41题的计数排序备用程序，不见于此次核对的考纲答案页，不据此认定为官方评分细则。2011年第44题还补写了首问的换算过程。
- 另有录入/排版差异，不能归结为两个出版物答案不同：例如2011年第42题程序出现 ~M _ Search~ 、 ~start1! = end1~ 等OCR问题；2012年第44题指令序列与流水线表格被拆成散行；2014年第41题设计思想末尾漏录 =d+1= 中的 =+1= 。切换考纲源稿时已修复这些问题，流水线表格按考纲时间单元重建；原印文中的程序和算法不擅自改写。
- 现有2015年考纲扫描件在书内第73页后转入出版声明，缺少2014年第46题续文与第47题；两题后半已用2016年考纲书内第55～56页核对，主要答案相同。原扫描PDF未改动。

现行版本中，除2013年按指定保留汇编解析外，其余上述年份已换用考纲答案；旧版题型示例的答案与详细解析由本仓库自行编写，已标注为自制、非官方。
