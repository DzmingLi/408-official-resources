#+title: 408 官方考试资料

本仓库用于收录全国硕士研究生招生考试计算机学科专业基础（俗称408）的官方相关资料，包括：

- 官方发布的考试大纲
- 历年真题与评分标准
- 官方发布的题型示例

真题和题型示例以教育部教育考试院（原教育部考试中心）出版的官方考试大纲为准。资料部分来自网络，部分来自自购扫描，采用 Typst 重新排版，并使用绘图包和矢量图标重绘部分图形。

2009—2014年真题答案可分别在2010、2012、2013、2015、2016年考试大纲的附录中核对，不要求一定具备真题次年的那一版考纲。2009—2012、2014年的答案现按考纲录入，不收录汇编另加的评分说明和扩写；2013年按指定继续保留高等教育出版社2015年《考研计算机专业基础综合历年真题标准解析》的解析。

目前没有明确资料给出考场试卷的排版参数，模板仍在完善中，目标是尽可能真实还原官方排版。欢迎熟悉相关字体、排版或印刷流程的读者提供建议。

真题文字订正及考纲范围变更标记统一记录于 [[file:真题订正.org][真题订正与注解]]，其中包括2013年第37题的HDLC删除线标记；考试大纲文件仅保留考纲内容。新版题型示例复用了历年真题，本仓库仅保留旧版题型示例。示例解析为本仓库整理，非官方评分标准。

* 目录

- =考试大纲/=：跟随最新考试大纲更新，按四门专业课整理为 Org 文件。
- =真题订正.org=：真题文字订正、考纲范围变更标记及学习注解的统一记录。
- =历年真题+参考解答/=：各年份试题和已有参考答案的 Typst 源文件。
- =题型示例/=：官方旧版题型示例及整理解析。
- =分类汇编/=：按考试大纲分讲的分类汇编；仅按需求逐讲增加，收录年份截止2022年，保留2023～2026年整卷练习。
- =内容来源/=：官方扫描资料，使用 Git LFS 保存。

如发现录入错字、图片或排版错误，欢迎提交 Issue 或 PR，并指出对应的官方资料位置。

* PDF 与构建

PDF 通过 [[https://github.com/DzmingLi/408-official-resources/releases][GitHub Releases]] 提供，随仓库更新自动构建。运行 =nix build= 后，输出位于 =result/=，只包含 PDF。

- =年份.pdf=：阅读版。
- =年份-print.pdf=：小册子打印版，推荐 B5 纸张，按双面打印机的翻页方向设置打印。
- =年份-answers.pdf= 与 =年份-answers-print.pdf=：参考答案阅读版、打印版。
- =年份-sample.pdf= 与 =年份-sample-print.pdf=：题型示例阅读版、打印版。
- =年份-sample-answers.pdf= 与 =年份-sample-answers-print.pdf=：题型示例解析阅读版、打印版。

分类汇编采用与数学仓库相同的 A4 预览机制，运行 =nix build .#collections --out-link result-collections=。当前包含计算机网络、数据结构、操作系统，以及计算机组成原理。每讲内部按考纲的知识点设置子标题，真题标明原年份和题号；示例只标“旧版题型示例”。2010年第47题（介质访问控制与停止－等待）收录于介质访问控制汇编；多知识点题按下述统一规则归类，不重复收录。分类汇编的年份限制不影响历年试卷构建与发布。

计算机组成原理按 =考试大纲/计算机组成原理.org= 的六章组织，共28讲及同序答案，收录2009—2022年180道真题（153道选择题、27道综合题）及4道旧版题型示例，保留2023—2026年整卷。独立分类清单为 =scripts/coa-collection-plan.py=。2013年第15题（海明码检/纠错）、第20题（RAID）依赖现行考纲已移除的条目，原卷保留，分类汇编排除；未有题目的“数制与编码”不生成空白PDF。2009年第11题考查指令周期，已补入“指令执行过程”，不按固定题号段误归数据结构。

计算机性能指标中，2010、2014、2017年第12题的“执行时间”或“运行时间”已按题意明确为“CPU执行时间”，同步更新历年试题与分类汇编；原表述及订正理由见 [[file:真题订正.org::*计算机性能指标][计算机性能指标的订正与注解]]。2012年第12题明确区分CPU时间与I/O时间，保留其总运行时间的表述。上述为仓库术语订正，非官方原文变更，数值、选项和答案不变。

组成原理跨考点题仍整题归入最后实际考查的考纲结点：2012年第43题和2022年第44题归入DMA方式，2013年第43题归入总线事务和定时，2014年第44题归入流水线冒险，2019年第45题归入异常和中断的检测与响应。2014年第45题、2016年第45题同时涉及组成原理与操作系统，分别在两门科目保留完整题目，各科内部不重复；2019年第44题涉及磁盘调度、驱动程序，只在操作系统收录。2014年第45题、2017年第44题补入前题必要程序或图表背景；2015年第43、44题已同讲相邻，直接共用前题数据通路图，不重复附图。2016年第44题、2017年第43、44题的答案按2018年考纲书内54、73～74页人工补录。选择题仅列答案字母，综合题保留原有答案内容与出处政策；28讲暂不跨节凑页合并。

操作系统按 =考试大纲/操作系统.org= 的五章组织，收录2009—2022年171道真题（140道选择题、31道综合题）和4道旧版题型示例；保留2023—2026年整卷。分类清单独立维护在 =scripts/os-collection-plan.py=，仍由统一提取器从原卷提取题干与图表、由答案提取器生成同序答案。题号覆盖与唯一归属有回归测试。2014年第45题、2017年第45题、2018年第45题、2019年第46题附上前题的必要代码或图表背景，不把前题小问作为新题重复收录。2019年第43题（哲学家同步）、第44题（磁盘）属于操作系统，2019年第45题的组成原理小问不另收录。2016年第47题（FAT文件系统）已补入“文件”，答案按2018年考纲书内56页补录；2016、2017年的其他操作系统综合题补录来源为同版书内54～55、74～75页。

操作系统共输出15讲及对应答案：基本概念与发展历程、程序运行环境、操作系统引导、进程与线程、CPU调度与上下文切换、同步与互斥、死锁、内存管理基础、虚拟内存管理、文件、目录、文件系统、I/O管理基础、设备独立软件、外存管理。基本概念与发展历程正式合并并检查一页上限；其他讲暂不跨节凑页。空的操作系统结构、虚拟机等考纲条目不生成空白PDF。长程序答案允许按代码行分页，不以整块禁止分页造成溢出。

每份分类汇编同时输出 =讲名-题目.pdf= 和 =讲名-answers.pdf=，答案版无封面，沿用题目版的分类、题序与正式合并关系。选择题仅列答案字母，不刊解析；综合题保留对应解析。2009—2012、2014年提取考纲版答案，2013年保留汇编解析。原含选择题解析的全文存于不提交、不参与构建的 =本地参考/高教社汇编解析/=。2016、2017年缺少的来源已依据扫描版人工补录。旧版题型示例的综合题解析注明为整理解析，非官方参考答案，其原选择题解析亦保留在 =本地参考/旧版题型示例解析/=。运行 =python3 scripts/extract-collection-answers.py --patch= 生成待应用补丁，=--check= 检查题答同步；构建会自动执行同步检查。

以下记录的是切换考纲版本前的旧稿差异。主要算法、结果、表格及多数解释可在考纲中找到，并非全部由汇编另行撰写；但“答案要点相同”不等于汇编全文都是官方原文。旧稿差异包括：

- 2009年第41题，考纲仅写“举例说明（略）”，现稿增加两个反例图及说明；第43题考纲只列2.5%、0.1%并略去计算，现稿补写计算过程；第46题现稿增加地址划分图及解释，部分过程表述与考纲不同。
- 2010年第41题，考纲给散列表与12/7、18/7两个结果，现稿另列散列及平均查找长度的逐步计算；其余综合题的主要答案可在考纲中对应找到。
- 2011—2014年现稿中的大量“评分说明”、分问分值，以及2011年第42题的备用归并程序、2013年第41题的计数排序备用程序，不见于此次核对的考纲答案页，不据此认定为官方评分细则。2011年第44题还补写了首问的换算过程。
- 另有录入/排版差异，不能归结为两个出版物答案不同：例如2011年第42题程序出现 ~M _ Search~、~start1! = end1~ 等OCR问题；2012年第44题指令序列与流水线表格被拆成散行；2014年第41题设计思想末尾漏录 =d+1= 中的 =+1=。切换考纲源稿时已修复这些问题，流水线表格按考纲时间单元重建；原印文中的程序和算法不擅自改写。
- 现有2015年考纲扫描件在书内第73页后转入出版声明，缺少2014年第46题续文与第47题；两题后半已用2016年考纲书内第55～56页核对，主要答案相同。原扫描PDF未改动。

现行版本中，除2013年按指定保留汇编解析外，其余上述年份已换用考纲答案；旧版题型示例整理解析仍注明为非官方。

数据结构按 =考试大纲/数据结构.org= 的七章组织，共31讲及同序答案，收录2009—2022年180道真题（153道选择题、27道综合题）及4道旧版题型示例，保留2023—2026年整卷。本次新增27讲，包括算法、线性表、栈队列与数组、树、查找、排序；有题的小节单独输出，空考点保留在分类清单中，不生成空白PDF。新增分类清单为 =scripts/ds-collection-plan.py=，原“图”的清单仍由统一提取器维护，不重复收录。线性表算法设计题归入“线性表的应用”；2016年第43题按枢轴划分归入“快速排序”，2012年第41题按最佳归并策略归入“外部排序”，2022年第41题按二叉搜索树判定归入“树形查找”。2016年第42、43题及2017年第41题答案按2018年考纲书内51～54、70～72页人工补录，长程序允许按代码行分页。各讲暂不跨节凑页合并。

数据结构“图”仍按考纲四项分别构建：“图的基本概念”“图的存储及基本操作”“图的遍历”“图的基本应用”。最后一讲按最小生成树、最短路径、拓扑排序、关键路径细分；旧版Dijkstra示例仅收录于数据结构，2014年第42题仅收录于计网路由算法汇编，不重复收录。

四科汇编的整卷联合检查覆盖2009—2022年全部658道真题，明确排除现行考纲移除的3道题后，检查655道题均至少收录一次。跨科共用的2014年第45题、2016年第45题仍按上述政策保留，各科内部题号唯一；不再仅靠常见题号段推断科目。

传输层按考纲分为“传输层提供的服务”“UDP协议”“TCP协议”三讲，仅收录截至2022年的真题，二级标题采用考纲原名；跨知识点综合题保留完整小问，按考纲顺序最后的实际考点归类，不重复收录。

分类规则：一道题涉及多个实际考查知识点时，按考纲先后顺序，归入最后出现的知识点所在汇编与分节；只作为背景或干扰选项出现的概念不计。题目不拆分、不重复收录。分类范围、收录政策与交叉说明只保留在仓库文档中，不印入汇编正文。

汇编只显示有题目的小节标题，名称和顺序遵照考纲；分类清单中的空考点保留供后续收录使用，不印入正文。

正式构建已将“传输层提供的服务＋UDP协议”合并为 =传输层提供的服务与UDP协议-题目.pdf=，将“FTP＋电子邮件”合并为 =FTP与电子邮件-题目.pdf=，不再输出原四份单独PDF。这两份凑页合并须恰为一页，超过一页时报错并要求重新拆分。另按指定，将“数据链路层的功能”置于 =流量控制与可靠传输机制-题目.pdf= 开头，将“网络应用模型”置于 =DNS系统-题目.pdf= 开头，这两份指定合并不受一页限制；不再输出被并入讲的单独PDF。各讲独立源稿、标题和题目归属保留，构建检查每讲只输出一次且不跨顶级章节。

物理层的“通信基础”和“传输介质”按考纲次序合并为 =物理层分类汇编-题目.pdf= 及 =物理层分类汇编-answers.pdf=，不再输出两讲单独的PDF，也不受一页限制。2013年第34题（10BaseT曼彻斯特信号）与2019年第34题（100BaseT的导向传输介质）均归入“局域网”的“以太网与IEEE 802.3”，不再归入物理层；物理层合并后共12道题，局域网共6道题，均未重复收录。局域网的小标题严格采用考纲的“局域网的基本概念与体系结构”“以太网与IEEE 802.3”“IEEE 802.11无线局域网”“VLAN基本概念与基本原理”，空的VLAN条目不打印。

不设“综合题”兜底分类，跨考点整题仍归入最后实际考查的考纲结点。2022年第47题归入IPv4的“ARP协议、DHCP协议与ICMP协议”；2010年第47题归入CSMA/CD，不另设综合应用分节。短讲可以按有题条目的实际顺序合并，跳过无题条目、允许连续多讲，但不得跨越计算机网络概述、物理层、数据链路层、网络层、传输层、应用层等顶级章节；不缩字号、不压间距，以实际编译不超过一页为准。

OSI模型题按实际考点归层：2016年第33题归入网络层设备，2022年第33题归入数据链路层的功能。整体分层、协议要素、跨层封装以及考纲未单设章节的会话层和表示层题仍收录在概述，不因题干出现OSI字样一律归入概述，也不把OSI会话层、表示层题强行归为应用层协议题。

计算机网络2009—2022年共有127道真题；分类汇编排除依赖已删除HDLC协议条目的2013年第37题，实际收录126道真题（111道选择题、15道综合题），另收录3道相关旧版题型示例。原卷保留该题，对“HDLC协议”加删除线并附编注。组帧暂不单独输出空白汇编。物理层补有“传输介质”（含物理层接口特性）；2016年第35题归入数据链路层设备。测试按逐年题号清单及明确的排除清单检查覆盖、无重复以及2023—2026年保留卷不混入。

应用层按考纲分为“网络应用模型”“DNS系统”“FTP”“电子邮件”“WWW”五讲，共14题，收录至2022年，分节使用考纲原名。2011年第47题因实际考查HTTP归入WWW，2021年第47题因实际考查域名解析归入DNS系统，两题均保留完整跨层小问，不再在链路层重复收录。2020年第40题同时考查DNS和HTTP，归入后出现的HTTP；仅以Web访问为背景而实际考查NAT的2020年第47题仍归入IPv4。旧版题型示例没有应用层题目，本次不另行添加。

网络层按考纲顺序提供“网络层的功能”“路由算法”“IPv4”“路由协议”“网络层设备”五讲。分节采用考纲原名；RIP协议更新题归入“路由协议”，不再与通用距离-向量算法混编。2017年第37题同时考查RIP、OSPF、BGP，归入最后的“BGP路由协议”；2018年第47题同时考查分片与子网划分，归入后者；2019年第47题考查路由器与交换机选择，归入“网络层设备”。当前截止2022年的收录范围内未找到独立考查IPv6、IP组播、移动IP的题目，暂不生成这些讲的空白PDF。
