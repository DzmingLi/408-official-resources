#+title: 408 官方考试资料

本仓库用于整理并收录全国硕士研究生招生考试计算机学科专业基础（俗称408）的官方相关资料，采用 Typst 作为排版语言，包括：

- 官方发布的考试大纲
- 历年真题与评分标准
- 官方曾经发布的旧版题型示例

这些资料全都来自每年教育部教育考试院（原教育部考试中心）出版的官方考试大纲。

目前仍然缺失的资料是《2014年全国硕士研究生入学统一考试计算机科学与技术学科联考计算机学科专业基础综合考试大纲》。如果您手里有实体书或者PDF可以通过邮件联系仓库作者。

目前的试卷排版我随便排的，它也不具备什么现实依据。目前没有明确资料给出考场试卷的排版参数, 一个可能的方案是靠每年的考生回忆试卷尺寸，字体，间距什么的，尽可能还原考场真题的排版也在路线图之中。

真题文字订正及考纲范围变更标记统一记录于 [[file:真题订正.org][真题订正与注解]]。新版题型示例复用了历年真题，本仓库仅保留旧版题型示例。

* 目录

- =考试大纲/= ：跟随每年发布的考试大纲更新
- =历年真题+参考解答/= ：各年份试题和已有参考答案的 Typst 源文件。
- =旧版题型示例/= ：2015年之前的的考试大纲使用的题型示例，之后年份的考试大纲的题型示例是从真题摘出来的，仅公开题目。
- [[file:分类汇编/README.org][分类汇编/]]：按考试大纲分讲的分类汇编；完整分类覆盖2009～2026年全部真题，自行构建可选择起止年份及A4/A5纸张。
- =内容来源/= ：官方扫描资料，用来备查。如发现录入错字、图片或排版错误，欢迎提交 Issue 或 PR，并指出对应的官方资料位置。

- =年份-print.pdf= ：小册子打印版，使用 ISO B4 横向纸张，100% 实际大小、双面短边翻转。
- =年份-answers.pdf= 与 =年份-answers-print.pdf= ：参考答案阅读版、打印版。

* 答案来源

2009—2014年试卷的综合应用题（第41—47题）统一采用高等教育出版社2015版《考研计算机专业基础综合历年真题标准解析》中的参考答案及解析，保留书中评分说明和备用解法。编者为全国硕士研究生入学统一考试辅导用书编委会，ISBN 978-7-04-039404-7（2014年4月出版）。扫描件见 [[file:内容来源/2015年计算机历年真题标准解析.pdf][2015版历年真题标准解析]]。分类汇编同步采用同一来源；选择题仍只列答案字母，2015年及以后的答案来源不变。

旧版题型示例仅公开官方题目。原考纲未附参考答案，本地自制解析不纳入GitHub源码、发布PDF或分类汇编；分类汇编中的相应答案位置注明“原考纲未附本题参考答案”。
